# Curso PS2SDK

Repositorio de aprendizaje para desarrollar homebrew
en PlayStation 2 utilizando C y PS2SDK.

## Objetivo

Aprender los fundamentos necesarios para desarrollar
ELFtation Navigator (ETN).

## Contenido

- Bloque 0: Ecosistema PS2 y PS2SDK
- Bloque 1: Fundamentos de C necesarios para ETN
- Bloque 2: Compilación y ejecución
- Bloque 3: Vídeo e interfaz
- Bloque 4: Entradas del DualShock 2
- Bloque 5: Memoria y almacenamiento
- Bloque 6: Sistemas de archivos
- Bloque 7: Lanzamiento de ELF
- Bloque 8: Integración de conocimientos
