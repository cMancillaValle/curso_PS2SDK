
# Bloque 00: El ecosistema PS2

## Descripción

Este bloque introduce los conceptos fundamentales del desarrollo Homebrew para PlayStation 2. Su propósito es comprender el entorno de desarrollo y el papel de las herramientas que utilizaremos antes de comenzar a programar ELFtation Navigator (ETN).

## Objetivos

- Comprender qué es una aplicación Homebrew y cómo se ejecuta.
- Identificar los componentes del hardware de PS2 relevantes para el proyecto.
- Reconocer las herramientas y los recursos del ecosistema Homebrew.
- Entender nuestro entorno de desarrollo y el flujo de construcción de un ejecutable.

| 02 | Hardware de PS2 relevante para ETN |

## Resultado de aprendizaje

Al completar el bloque, conocemos los fundamentos del ecosistema Homebrew, las características del hardware relevantes para ETN y la función de las herramientas que utilizaremos para construir nuestros programas.

## Proyecto de referencia

**ELFtation Navigator (ETN)** es un explorador de archivos Homebrew para PlayStation 2, inspirado en herramientas como uLaunchELF.

Este bloque constituye la base conceptual para aprender las habilidades de programación y manejo de recursos necesarias para desarrollar ETN.
